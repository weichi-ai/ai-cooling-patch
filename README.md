# AI退烧贴

**纵然 AI 风姿千千万，休要给我一双熊猫眼。**

AI退烧贴（项目代号 LockPC）是一款 Windows 10/11 专注与睡眠保护工具，通过番茄钟强制离屏休息和定时睡眠保护，减少长时间使用电脑与 AI 对休息、睡眠的影响。不戒 AI，只退烧。

## 1.0 已实现功能

- 番茄专注：15/25/30/45/50/60 分钟专注，专注期间电脑正常使用。
- 强制休息：每轮专注结束后，覆盖全部显示器并阻断普通鼠标键盘操作。
- 自动循环：休息结束自动进入下一轮；默认 4 轮、休息 10 分钟。
- 睡眠保护：支持每日开始/结束时间、跨零点和按星期生效。
- 睡前提醒：开始前 30 秒置顶提醒；每晚可延迟一次 5/10/15/30 分钟。
- 自动解除：到计划结束时间自动恢复桌面操作。
- 异常恢复：运行状态原子化保存；程序重启后恢复未结束的番茄阶段或睡眠保护。
- 多显示器：每块显示器创建独立置顶覆盖层，热插拔后重建覆盖。
- 输入阻断：锁定期间使用 Windows 低级键盘钩子阻断常见键盘操作。
- 系统托盘：关闭主窗口后继续运行；计划执行期间拒绝普通退出。
- 开机启动：可在设置页写入当前用户的 Windows 登录启动项。
- 10 秒安全预览：可分别体验休息锁定和睡眠保护界面。
- 有理由中断：专注期可结束整个计划，休息期可提前撕贴；两者都必须填写至少 5 个字的理由。
- 数据分析：按最近 7 天汇总完成专注、完整休息率、中断时段、睡眠保护和延迟次数，并展示本地事件明细。
- 隐私边界：不读取应用名称、网站、窗口标题、键盘输入或屏幕内容。
- 撕贴反馈：休息中可填写理由提前撕贴；确认后播放撕起飞离动效和可关闭的短音效。
- 关于与更新：位于“设置 → 关于与更新”，显示当前版本、版本记录和 GitHub 更新入口。

## 获取与运行

从 GitHub Releases 下载 `AI退烧贴-v1.0.0-win-x64-self-contained.zip`，完整解压后运行 `LockPC.App.exe`。自包含版本无需安装 .NET；请勿只复制 exe，运行库需与主程序保持在同一目录。

首次体验建议：打开“专注” → “试贴休息模式（10 秒）”。试贴会真实阻断输入，并在 10 秒后自动揭下。

## GitHub 更新检查

应用默认使用以下公开 GitHub 仓库检查更新：

`https://github.com/weichi-ai/ai-cooling-patch`

开发测试可以设置 `LOCKPC_GITHUB_REPOSITORY_URL` 环境变量临时覆盖。没有网络时不影响专注、休息和睡眠保护功能。

## 开发构建

请先安装 .NET 8 SDK，然后运行：

```powershell
dotnet build .\LockPC.sln
```

## 安全边界

当前版本是应用级锁定，不是 Windows 登录锁屏。它不提供产品内提前解锁入口，并能抵抗普通关闭、切换窗口和 UI 进程异常，但无法阻止：

- `Ctrl+Alt+Delete` 安全桌面；
- 管理员结束进程、卸载或修改本机文件；
- 安全模式、断电、重装系统等拥有物理控制权的绕过方式。

因此当前版本不能宣称对本机管理员“绝对不可破解”。要进一步增强睡眠保护，需要增加管理员安装的 Windows 守护服务、受保护安装器和服务恢复策略。

## 数据位置

设置和运行状态默认保存在：

```text
%LOCALAPPDATA%\LockPC
```

可通过 `LOCKPC_DATA_DIR` 环境变量为开发测试指定其他目录。
